# 아메리칸 기후 카니발 포토부스 (금일중학교)

미국 문화와 **SDG 13(기후변화 대응)** 을 함께 담은 컨셉으로, 인생네컷처럼 4컷 사진을 만드는 학교 행사용 웹앱입니다.
설치나 빌드 없이 브라우저에서 바로 동작하고, 백엔드 서버나 과금되는 외부 서비스가 필요 없습니다.

## 실행 방법

카메라 사용 권한은 보안 컨텍스트(`http://localhost` 또는 `https://`)에서만 정상 동작하므로,
`index.html`을 더블클릭해서 여는 대신 아래처럼 간단한 로컬 서버로 실행해주세요.

**별도 설치 없이 (PowerShell, Windows 기본 내장):**
```
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

**Python이 설치되어 있다면:** `python -m http.server 8000`
**Node.js가 설치되어 있다면:** `npx serve .`

서버를 실행한 뒤 브라우저(Chrome, Edge 권장)에서 `http://localhost:8000` 으로 접속하고,
카메라 권한 요청이 뜨면 **허용**을 눌러주세요.

> 휴대폰으로 쓰려면 PC와 같은 와이파이에 연결한 뒤 `http://<PC의 IP>:8000` 으로 접속하면 됩니다.
> 다만 브라우저에 따라 `localhost`가 아닌 주소에서는 카메라를 막기도 하니, 행사 전에 꼭 한 번 시험해보세요.

## 학교 로고 넣기

모든 사진 아래쪽에 금일중학교 로고가 들어갑니다. 넣는 방법은 두 가지입니다.

1. 로고 이미지를 `assets/logo.png` 로 저장해두기 (앱이 자동으로 찾습니다)
2. 앱 첫 화면의 **로고 등록** 버튼을 눌러 이미지 고르기 (해당 브라우저에 저장돼 계속 쓰입니다)

둘 다 없으면 임시 엠블럼(파란 마름모 + 금일중)이 대신 표시됩니다. 자세한 내용은 `assets/README.txt` 참고.

## 사용 흐름

1. **포토 배경 선택** — 아래 4가지 배경 중 선택 (앱 전체 색도 함께 바뀜)
2. **배치 선택** — 1×4 스트립 또는 2×2 그리드
3. **필터 선택** — 원본 / 흑백
4. **촬영** — 10초 카운트다운 후 자동 촬영을 **8번** 반복 (급할 땐 "지금 찍기"로 바로 촬영)
5. **사진 고르기** — 찍은 8장 중 마음에 드는 **4장**을 고르면, 고른 순서대로 사진에 들어감
6. **결과** — **공유하기**(카카오톡·메시지 등) / **기기에 저장** / 다시 고르기 / 다시 찍기

촬영 중에는 전면(셀카)·후면 카메라를 **카메라 전환** 버튼으로 바꿀 수 있습니다.
전면일 때만 좌우를 뒤집어 보여주고, 후면일 때는 보이는 그대로 찍힙니다.

## 포토 배경 4종

| 배경 | 컨셉 | 들어간 요소 |
| --- | --- | --- |
| 성조기 카니발 | AMERICAN CLIMATE CARNIVAL | 성조기 캔턴·줄무늬, 축제 가랜드, 지구, 잎사귀 |
| 자유의 여신 | CLIMATE ACTION! | 여신상 왕관·횃불, 해수면 물결, 별 |
| 그린 루트 66 | GREEN ROUTE 66 | 레트로 고속도로 표지판, 선셋, 풍력발전기, 도로 |
| 국립공원 | PROTECT OUR PLANET | 빈티지 포스터 테두리, 산·침엽수림, 햇살 |

네 배경 모두 아래쪽에 **학교 로고 + 금일중학교 + SDG 13 뱃지 + 날짜**가 공통으로 들어갑니다.

## 파일 구조

```
index.html              # 앱 진입점, 6개 화면 마크업
css/style.css            # 전체 스타일 및 배경별 테마 색상
assets/                   # 학교 로고 파일을 두는 곳
js/paint.js                # 캔버스 드로잉 도구 모음 (별, 줄무늬, 왕관, 풍력, SDG 뱃지 등)
js/logo.js                  # 학교 로고 불러오기·등록·대체 엠블럼
js/frames.js                 # 포토 배경 4종 정의 — 새 배경을 추가하려면 이 파일만 수정
js/filters.js                 # 사진 필터(원본/흑백) 정의
js/camera.js                   # 카메라 스트림, 10초 카운트다운, 촬영 로직
js/compose.js                   # 고른 4장을 배치·배경으로 합성해 최종 이미지 생성
js/share.js                      # 결과 화면의 "공유하기"(Web Share API) 로직
js/app.js                         # 화면 전환 상태머신, 전체 흐름 연결
serve.ps1                          # Node/Python 없이 바로 쓸 수 있는 PowerShell 정적 서버
```

**배경을 더 추가하려면** `js/frames.js`의 `FRAMES` 배열에 항목을 하나 추가하면 됩니다.
각 항목은 `backdrop / header / footer` 세 개의 그리기 함수만 채우면 되고,
1×4와 2×2 양쪽에 같은 코드가 쓰이므로 좌표는 넘겨받은 레이아웃 정보(`r`)를 기준으로 계산하면 됩니다.

## 공유하기

결과 화면의 "공유하기"는 브라우저 내장 **Web Share API**를 사용합니다. 별도 계정 가입이나 API 키, 서버 설정이 전혀 필요 없습니다.
버튼을 누르면 기기의 공유 시트가 뜨고, 설치되어 있는 앱(카카오톡, 메시지, 메일 등) 중 원하는 곳으로 사진 파일을 바로 보낼 수 있습니다.

다만 이 기능은 브라우저/기기 지원 범위 안에서만 동작합니다. 지원하지 않는 환경에서는 버튼이 자동으로 비활성화되고 안내 문구가 표시되니,
이 경우 **기기에 저장** 버튼으로 사진을 받으면 됩니다.

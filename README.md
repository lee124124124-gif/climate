# 학교 행사 포토부스

인생네컷/포토이즘 스타일로, 학교 행사에서 즉석 사진을 찍을 수 있는 웹앱입니다.
설치나 빌드 없이 브라우저에서 바로 동작하고, 백엔드 서버나 과금되는 외부 서비스가 필요 없습니다.

## 실행 방법

카메라 사용 권한은 보안 컨텍스트(`http://localhost` 또는 `https://`)에서만 정상 동작하므로,
`index.html`을 더블클릭해서 여는 대신 아래처럼 간단한 로컬 서버로 실행해주세요.

**별도 설치 없이 (PowerShell, Windows 기본 내장):**
```
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

**Python이 설치되어 있다면:**
```
python -m http.server 8000
```

**Node.js가 설치되어 있다면:**
```
npx serve .
```

서버를 실행한 뒤 브라우저(Chrome, Edge 권장)에서 `http://localhost:8000` 으로 접속하고,
카메라 권한 요청이 뜨면 **허용**을 눌러주세요.

## 사용 흐름

1. **행사 선택** — 체육대회 / 과학의날 / 졸업식 / 축제 중 선택 (테마·배경·장식이 자동 적용됨)
2. **배치 선택** — 1×4 스트립 또는 2×2 그리드
3. **필터 선택** — 원본 / 흑백 / 따뜻한 톤 / 차가운 톤
4. **촬영** — "촬영 시작"을 누르면 3-2-1 카운트다운 후 자동으로 4장을 촬영
5. **결과** — 완성된 사진을 확인하고 **공유하기** / **기기에 저장** 중 선택, 또는 다시 찍기 / 처음부터

## 공유하기

결과 화면의 "공유하기"는 브라우저 내장 **Web Share API**를 사용합니다. 별도 계정 가입이나 API 키, 서버 설정이 전혀 필요 없습니다.
버튼을 누르면 기기의 공유 시트가 뜨고, 설치되어 있는 앱(카카오톡, 메시지, 메일 등) 중 원하는 곳으로 사진 파일을 바로 보낼 수 있습니다.

다만 이 기능은 브라우저/기기 지원 범위 안에서만 동작합니다:
- 모바일 브라우저(Chrome, Safari 등)에서는 대부분 잘 지원돼요.
- 일부 구형 브라우저나 지원하지 않는 환경에서는 "공유하기" 버튼이 자동으로 비활성화되고 안내 문구가 표시됩니다 — 이 경우 **기기에 저장** 버튼으로 사진을 받으면 됩니다.

## 파일 구조

```
index.html            # 앱 진입점, 5개 화면 마크업
css/style.css          # 전체 스타일 및 행사별 테마 색상
js/themes.js            # 행사별 테마(색상, 장식, 문구) 정의 — 새 행사 추가 시 이 파일만 수정
js/filters.js            # 사진 필터(원본/흑백/따뜻한 톤/차가운 톤) 정의
js/camera.js              # 카메라 스트림, 3-2-1 카운트다운, 촬영 로직
js/compose.js               # 촬영된 4장을 배치·테마로 합성해 최종 이미지 생성
js/share.js                   # 결과 화면의 "공유하기"(Web Share API) 로직
js/app.js                        # 화면 전환 상태머신, 전체 흐름 연결
serve.ps1                          # Node/Python 없이 바로 쓸 수 있는 PowerShell 정적 서버
```

행사를 더 추가하고 싶다면 `js/themes.js`의 `THEMES` 배열에 항목을 하나 추가하면 됩니다.

금일중학교 로고를 여기에 넣어주세요.

파일 이름을 "logo.png" 로 저장해서 이 폴더(assets)에 두면,
앱이 자동으로 찾아서 모든 사진 아래쪽 로고 자리에 넣어줍니다.

  assets/logo.png      <-- 이렇게 두면 됩니다
  (logo.jpg / logo.jpeg / logo.webp / logo.svg 도 인식합니다)

파일을 옮기기 어렵다면 앱 첫 화면 오른쪽 아래의 "로고 등록" 버튼을 눌러
이미지를 고르면 됩니다. 한 번 등록하면 그 브라우저에 저장돼서 계속 쓰입니다.

로고가 없을 때는 임시 엠블럼(파란 마름모 + 금일중)이 대신 표시됩니다.

팁: 배경이 투명한 PNG를 쓰면 가장 깔끔하게 나옵니다.
